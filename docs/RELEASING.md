# 发布

```sh
scripts/release.sh <ipa> <tag> <标题后缀> <说明文件>
```

## 为什么是脚本

**版本号从文件名里读，不从人手里读。**

**第 130 轮我在说明里写了 919，而文件是 918——数字是打出来的，而打出来的东西会错。**

**文件名本身也来自构建产物**（`package_ipa.sh` 读 `.app/Info.plist`），所以这条链上的每个数字都来自产物。

## 脚本会拒绝

- **文件名不带版本**——不猜。
- **说明文件不存在**——否则会发一个空的发布。
- **产物不存在**。

## 脚本会验证

**发布之后立即匿名下载一次。**只对已认证用户可用的链接不是链接。

## 产物从哪来

```sh
gh run download <run-id> -D /tmp/ipa
cp /tmp/ipa/*/PocketDSH-*.ipa .
```

**文件名形如 `PocketDSH-0.1.20261124-918-unsigned.ipa`。**
