## 三个原始目标

### (1) 修复 BRE 引擎缺陷，让 grep/sed/awk 与参考实现一致

**已达成。** 差分对比从 0 涨到 **319 条**，`grep`、`sed`、`awk` 与 qemu 下同一个 busybox
**逐字节一致**。

会话中修的实质性缺陷（部分）：

| 缺陷 | 表现 |
| --- | --- |
| `UZP1`/`ZIP1`/`ZIP2` 三者被实现成同一个交织 | 182 条差分用例都没发现，写单测时才发现 |
| `SQXTN` 缺少按源宽度符号扩展 | -40000 被钳到 32767 而不是 -32768 |
| 绝对符号链接在宿主命名空间解析 | `/usr/bin/*` 全部加载失败 |
| guest 只有 1 MB 内存 | 递归约 670 层就死 |
| `sysinfo` 系统调用完全缺失 | `free` 打印三十位数字 |

### (2) 扩展 M2/M3 扫描覆盖并修复指令缺陷

**已达成。** M2 从 64 涨到 **163**，M3 从 59 涨到 **93**。
新增的解码守卫检查覆盖 **70/70** 条规则（原先的工具只覆盖 29/73）。

### (3) 改进 iOS 端 UI 与功能

## 本次会话最有价值的几件事

### 一、让 qemu 真正 chroot

**此前「qemu 未 chroot」被当成不可改变的约束，反复记录「这是环境差异」。**

**实际上机器有 root 权限、系统里有 `qemu-aarch64-static`——这个条件一直都在。**

改了之后：

| 变化 | 收益 |
| --- | --- |
| `/proc`、`/etc`、`pwd`、符号链接可以对比了 | 直接多出 **16 条**用例 |
| 五种「假差异」全部消失 | 少走很多弯路 |

### 二、把「沉默的失败」变成响亮的

**这个项目最贵的错误都是沉默的**——程序继续跑、检查继续绿、文档继续读得通。

见 [E2-BACKEND.md 最后一节](E2-BACKEND.md)：五种反复出现的错误模式，每种配一条防法。

### 三、验证成本从 21 分钟降到 9 分钟

| 改动 | 耗时 |
| --- | --- |
| 原始（套件跑了两遍） | 1277 秒 |
| 复用已测计数 | 716 秒 |
| 并行两个二进制 | 440 秒 ← **后来回退了** |
| 回退并行（间歇性失败） | ~570 秒 |

**并行那一版省了 130 秒，但引入了间歇性失败——正确性换速度不划算，已回退。**
用例之间现在用「列目录、删新增」隔离，代价是一次 `ls`。
