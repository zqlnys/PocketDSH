Tier C iSH runtime in iOS Simulator
Run: https://github.com/zqlnys/PocketDSH/actions/runs/43730347674
App: com.example.tiercprobe
Device: iPhone 17 Pro Max, iOS 26.2 simulator
JIT: no

Command:
/bin/sh -c 'echo tier-c-probe-ok; uname -a; cat /etc/alpine-release'

Captured output:
tier-c-probe-ok
Linux pocketdsh 4.20.69-ish SUPER AWESOME ... i686 Linux

Result: the iSH interpreter and Alpine rootfs execute inside the iOS
Simulator process without JIT.

Known issue:
The probe UI leaves the foreground after the one-shot iSH run. The
emulated task cleanup / app lifecycle and the iSH host thread need
isolation before integrating this into the main PocketDSH app. The main
app does not link iSH yet. This is not a claim that Tier C is available
inside PocketDSH.
