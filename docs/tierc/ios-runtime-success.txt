Tier C iSH runtime in iOS Simulator
Run: https://github.com/zqlnys/PocketDSH/actions/runs/43731444339
App: com.example.tiercprobe
Device: iPhone 17 Pro Max, iOS 26.2 simulator
JIT: no

Command:
/bin/sh -c 'echo tier-c-probe-ok; uname -a; cat /etc/alpine-release'

Captured output:
tier-c-probe-ok
Linux pocketdsh 4.20.69-ish SUPER AWESOME ... i686 Linux

Result:
- iSH interpreter and Alpine rootfs execute inside the iOS Simulator process.
- No JIT.
- The probe UI stays in the foreground and displays the real Linux output.

Known issue:
The emulated shell task is still running after the command output; this
probe uses a 3-second observation window. A persistent-shell command
protocol is required before integrating this into the main PocketDSH app.
The main app does not link iSH yet.
